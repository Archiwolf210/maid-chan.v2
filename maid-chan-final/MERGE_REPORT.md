### 2. Функция `get_open_topics`
В `autonomous.py` используется `from app.repositories.__init__ import get_open_topics`, но эта функция не экспортируется из `__init__.py`.

**Рекомендация:** Добавить функцию в `repositories/__init__.py`:
```python
def get_open_topics(uid: str, limit: int = 5) -> List[Dict]:
    """Get open pending topics for user."""
    with db() as c:
        rows = c.execute(
            "SELECT id, topic, context, importance FROM pending_topics "
            "WHERE user_id=? AND status='open' ORDER BY importance DESC LIMIT ?",
            (uid, limit)
        ).fetchall()
        return [dict(r) for r in rows]
```

### 3. Интеграция с Key Memories для писем
